プライバシーポリシー

本ポリシーは、YouTubeチャンネル「リリーの政治ニュース」の運営者が自分で使うために作成したアプリ「リリーの政治ニュース 投稿ツール」（以下「本ツール」）での情報の取り扱いを定めるものです。

1. 本ツールの目的

本ツールは、運営者が自分のYouTubeチャンネルに動画をアップロードし、動画の情報（タイトル・説明・サムネイル・公開設定など）を管理するためだけに使用します。運営者以外の利用は想定していません。

2. 利用するYouTube APIのデータ

本ツールはYouTube API Servicesを利用し、Googleアカウントでの同意を得たうえで、次の権限を使用します。

  • youtube.upload：動画のアップロード
  • youtube.force-ssl：自分のチャンネルの動画情報・コメントの取得と管理

3. 情報の保存

認証で得たアクセストークンは、運営者のパソコン内にだけ保存します。外部のサーバーには送信・保存しません。

4. 第三者への提供

本ツールで取得した情報を、第三者に販売・提供・共有することはありません。

5. アクセス権の取り消し

本ツールに与えたアクセス権は、Googleアカウントのセキュリティ設定（https://security.google.com/settings/security/permissions）からいつでも取り消せます。

6. YouTube・Googleの規約

本ツールはYouTube API Servicesを利用しています。利用にあたっては、YouTube利用規約およびGoogleプライバシーポリシーが適用されます。

7. お問い合わせ

本ポリシーについてのお問い合わせは、YouTubeチャンネル「リリーの政治ニュース」までお願いします。
